- 2026-11-18(서가 시안): 제목용 명조는 함렛(Hahmlet)으로 확정한다(책등·캡션·상세 제목·로고). 이름은 오솔문고로 하되 화면 표기는 영문만 쓴다: OSOL LIBRARY(로고는 OSOL + LIBRARY, 책등·표지 작은 표기는 OSOL). 서가 시안 기준이며, 실제 사이트(`src/`)의 이름·표기와 채택 여부는 서가 이식을 결정할 때 함께 바꾼다.
