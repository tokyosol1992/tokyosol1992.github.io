헤더 상태 정지 화면

Figma로 옮겨 수정할 때 쓰는 화면입니다. 위 프로토타입과 같은 마크업이고, 스크롤하면 위 헤더가 ①에서 ②로 바뀝니다.

① 맨 위투명 · 히어로 위에 얹힘
② 스크롤 후블러 pill · 폭 축소 · 현재 섹션 [ ]
③ 모바일메뉴 버튼 → 전체 화면 시트
맨 위배경·테두리 투명, top: 20px fixed. 로고와 메뉴 글자만 보입니다.
스크롤 24px 이상blur(24px) saturate(1.4) + 반투명 면 + 얇은 테두리, 폭 1200 → 980, 0.5s 전환.
현재 위치보고 있는 섹션이 [About]처럼 파란 괄호로 표시됩니다.
모바일 <720px로고 + 버튼. 시트는 큰 글자 링크 4개, 하단에 메일과 서울 시각.
