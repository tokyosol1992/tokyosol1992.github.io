추천 조합: 호버

  • 메뉴·링크 → 텍스트 롤. 글자가 위로 굴러 올라가며 흰색으로 바뀝니다. 한글도 폭이 안 변합니다.
  • 카드 → 스포트라이트. 마우스를 따라 파란 빛과 테두리가 움직입니다. 연기·파동과 같은 파랑입니다.
  • Library 행 → 행 슬라이드. 지금 행 hover를 살려서 파란 면이 차오르고 썸네일이 따라옵니다.

추천 조합: 진입

  • 섹션 제목 → 블러 텍스트. 단어가 흐릿하게 떠올라 선명해집니다.
  • 페이지 이동 → 하프톤 리빌. 사이트의 점 패턴이 걷히며 새 페이지가 보입니다. 스크램블을 대신합니다.
  • About 숫자 → 카운트업. 8년 차, 2016이 올라갑니다.
